# Notes

How Stardate was worked out and built. The emulator's core came from [Confederation](https://github.com/jeffnyman/confederation), whose notes explain the processor, the DOS layer, the timer and keyboard, and saved states in full; these notes cover what's different here.

- [Project layout](project-layout.md): the core and the player, the tests, the builds.
- [The games](the-games.md): the three games, what each needs from the machine, and the display they're drawn on.

The games played through, and the driver that played them, are in [tools/](../tools/README.md); the walkthroughs, corrected from those plays, are in [walkthroughs/](../walkthroughs).
